# Retail Sales Performance Analysis using Power BI

## Project Overview
This project analyzes retail sales data to uncover insights related to sales trends, profitability, regional performance, and discount strategies using Power BI.

## Business Objective
The goal of this project was to identify key business insights that can help improve profitability and support decision-making.

## Tools Used
- Power BI
- DAX
- Excel/CSV
- Data Visualization

## Dashboard Features
- KPI cards for Sales, Profit, and Profit Margin
- Monthly sales trend analysis
- Regional performance comparison
- Top-selling products analysis
- Discount vs Profit analysis
- Interactive slicers and filters

## Key Insights
- Higher discounts were associated with lower profitability.
- Technology category generated the highest revenue.
- Some products generated strong sales but weak profit margins.
- Regional sales and profitability varied significantly.

## Recommendations
- Reduce excessive discounting on low-margin products.
- Focus on high-profit categories and regions.
- Improve strategies for underperforming segments.
